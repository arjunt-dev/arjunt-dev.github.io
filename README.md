# Arjun T - Developer Portfolio

A modern, responsive portfolio website showcasing my work as a Full Stack Developer & Security Analyst. Built with React, Vite, and Tailwind CSS, featuring a professional monochrome pastel theme with dark/light mode support.

## Features

- **Responsive Design** - Fully optimized for desktop, tablet, and mobile devices
- **Dark/Light Mode** - Professional monochrome pastel theme with smooth transitions
- **Smooth Animations** - Scroll-triggered fade-in effects and hover interactions
- **Modern UI Components** - Glass-morphism effects and clean card layouts
- **Fast Performance** - Built with Vite for lightning-fast load times
- **Accessible** - WCAG compliant with proper contrast ratios

## Design Philosophy

The portfolio features a **monochrome pastel theme** that prioritizes professionalism and readability:

- **Dark Mode** : Deep zinc/neutral gradients with soft gray accents
- **Light Mode** : Stone/neutral backgrounds with elegant gray tones
- **No Distractions** : Focused on content with subtle, professional styling
- **High Contrast** : Excellent readability in both themes

## Tech Stack

- **Frontend Framework** : React 19.2.0
- **Build Tool** : Vite 7.2.2
- **Styling** : Tailwind CSS 4.1
- **Icons** : Lucide React
- **Deployment** : GitHub Pages
- **Language** : JavaScript (ES6+)
